# 🤖 Hugging Face Flashcard Generator

An AI-powered flashcard generator built with Python and Hugging Face InferenceClient.

This project allows users to enter any study topic and automatically generates **5 short and useful study flashcards** using a Hugging Face language model. It also measures the model's response time so different AI models can be compared.

---

## 🚀 Features

- 🧠 AI-generated study flashcards
- 📚 Generate 5 flashcards from any topic
- 💬 Short questions and answers
- 🎓 Suitable for computer science students
- ⚡ Measures AI response latency
- 🔄 Supports switching between different Hugging Face models
- 🔐 Uses environment variables for API token security
- 🐍 Built with Python

---

## 🛠️ Technologies Used

- **Python**
- **Hugging Face Hub**
- **Hugging Face InferenceClient**
- **Git & GitHub**
- **Large Language Models (LLMs)**
